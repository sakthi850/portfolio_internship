# Sri Sakthi G — Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a new GitHub repository (for example, `sakthi850.github.io`).
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing
- Verify the phone number, email, CGPA and education details.
- Add your LinkedIn URL if you want it displayed.
- Confirm that the S-CADE live link and project repository are accessible.
- Add project screenshots or a demo video if available.

The portfolio uses information supplied in the conversation and previous resume. Update anything that has changed before sharing it with recruiters.
